PersonalOS Calendar

A personal Windows and Obsidian automation program for organizing notes, schedules, and file references.

Google Calendar

Creates events from explicit user instructions and queries the connected primary calendar to display schedules and check for duplicate events.

Google Drive metadata

Uses read-only file metadata to match locally managed files to their Google Drive IDs and web links. The Drive API integration does not download file contents, upload, edit, or delete files.

Runs in your own environment

The program runs locally on Windows alongside an Obsidian vault. Google authorization credentials are stored in the user's local environment, separately for Calendar and Drive.
